# Admin-Dashboard
A non-responsive dashboard project built as per challenge for The Odin Project curriculum

## Features
- Primarily utilized the grid instead of using flexbox for the layout.
- Changed eye svg into trash icon as an alternative.
-  Placed original characters and their usual interactions as content instead of placeholders.

## Programming Languages Used
- HTML
- CSS
